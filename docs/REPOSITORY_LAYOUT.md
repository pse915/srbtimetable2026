# 파일 정리 범위

2026-10-20 정리에서는 루트의 분석·검증 보고서 9개를 `docs/reports/`로 이동했습니다.
README와 배포 문서의 보고서 경로, 기능 목록 생성 도구의 출력 위치를 함께 수정했습니다.

## 그대로 보존한 파일

- 루트의 Python 실행 파일 전체: Cloud 실행 설정을 확인하지 않은 상태에서 이동하지 않습니다.
- `backend/`, `frontend/`, `frontend/dist/`: React 후보 실행 및 빌드 파일입니다.
- `legacy/`: `backend/domain/program.py`가 원본 코드를 실행 중에 읽습니다. 삭제하면 안 됩니다.
- `native-optimization/`: 별도 Streamlit 후보 및 팝업 테스트의 참조 대상입니다.
- `tests/`, `tools/`, 설정, 의존성 파일: 검증 및 배포에 필요합니다.
- 성능 JSON, 체크섬, 패치, 스크린샷: 과거 검증 기록과 참조 경로를 보존합니다. 기존 체크섬은 당시 산출물의 기록이며 이번 정리본의 체크섬이 아닙니다.

## 검증과 제한

정리 전후 앱 소스·빌드·설정·의존성의 바이트 동일성과 이동한 보고서의 내용 동일성을 확인합니다.
Google Sheets 접근, 관리자 로그인, 저장 요청을 수행하지 않습니다. 실제 Cloud 배포 설정과 운영 화면 검증은 포함하지 않습니다.
문서 이동만으로 앱 동작이 바뀌지 않도록 범위를 제한했습니다.

## 복구

이 정리 변경을 Git에서 revert하면 기존 경로로 돌아갑니다. Google Sheets 데이터 변경이나 복구는 필요하지 않습니다.
