# 보안·저장 안전성 검토

## 추가 보호

- React에 Secrets, 서비스 계정, 전체 Python 세션을 전달하지 않습니다. 현재 화면 모델과 검증된 사용자 입력만 전달합니다.
- 서버에 현재 역할·메뉴와 컨트롤 허용 목록을 다시 생성합니다. 숨긴 버튼만으로 권한을 판단하지 않습니다. 원본 소유권/관리자 검증도 그대로 실행합니다.
- 저장·메뉴·파일 시작/완료 요청 전에 계정 목록을 강제 재조회하고, 계정 삭제/권한 조회 실패 시 실행을 거절합니다. 전송 청크는 원본 60초 재검증을 적용합니다.
- 입력값 종류, 선택 인덱스, 표 열/행, 숫자 범위, 날짜, 체크 값, 파일 크기/형식을 검사합니다. 프론트엔드에서 권한/로그인 플래그를 설정할 수 없습니다.
- 요청 UUID, 화면 버전, 세션별 응답 원장으로 중복 요청을 방지합니다. 같은 UUID의 다른 내용은 거절합니다. 256개 응답을 보존하고 오래된 화면 버전 요청을 거절합니다.
- 이 원장은 프로세스 재시작·다른 세션 간 영구적인 exactly-once 저장 보장이 아닙니다. 타임아웃 후 최신 시트를 확인해야 합니다.
- 원본 Markdown/HTML 화면 조각은 DOMPurify로 정화하며 style/script/iframe/link 및 이벤트 속성을 허용하지 않습니다. 다운로드 파일은 원본 형식을 유지합니다.
- 시트 전체 값의 SHA-256 revision을 저장 직전에 대조하여 다른 사용자 수정 시 덮어쓰지 않습니다. 같은 프로세스 내 worksheet별 lock을 사용합니다.
- 저장 결과가 불확실하면 해당 시트 후속 저장을 막고 명시적으로 최신 자료를 다시 불러오도록 합니다.
- 기본 읽기 전용이고 원본 시트가 없을 때 새 시트를 자동 생성하지 않습니다.
- 50MB 제한, 순서 있는 제한 청크, 요청 ID 중복 방지, 파일 SHA-256 검사를 적용합니다.
- 원본 전역 st.cache_data에 세션 자료가 섞일 가능성을 줄이기 위해 세션별 캐시를 사용합니다.
- 개발 컨테이너의 CORS/XSRF 비활성 옵션을 제거했습니다.

## 보존한 원본 문제와 한계

1. **ID만으로 인증**합니다. 비밀번호/SSO 도입은 기존 로그인 호환성을 변경하므로 임의로 하지 않았습니다. 원본의 실패 제한을 유지했습니다.
2. **회원별 모든 탭 차단**은 빈 문자열을 저장하지만 빈 문자열은 기본 권한으로 해석됩니다. 호봉은 비게스트에게 항상 추가됩니다. 기존 스키마를 깨지 않도록 이 부분은 수정하지 않았습니다.
3. Google Sheets read/compare/write 사이에 다른 프로세스가 수정할 수 있습니다. 서버 수준 CAS나 원자적 트랜잭션은 없습니다. 여러 시트 저장 중 일부만 성공할 수 있습니다.
4. 원본 네트워크 타임아웃 스레드가 늦게 원격 쓰기를 완료할 수 있습니다. 취소 보장을 제공하지 않습니다.
5. 원본의 `save_work_data_to_gsheet`는 기본적으로 5개 워크시트 전체를 갱신하고 빈 표는 clear합니다. 새 버전도 저장 형식/업무 동작을 보존하며 충돌 감지를 추가했습니다.
6. 기존 HTML 다운로드 생성 함수 중 일부는 모든 시트 입력을 HTML escape하지 않습니다. 원본 출력 동등성 때문에 템플릿을 일괄 변경하지 않았습니다. 불신 입력이 포함된 HTML을 열 때의 실행 위험에 대한 별도 수정·출력 회귀 검증이 필요합니다.
7. 원본 복무/연계 업무에는 일부 실패 시 메모리 원복 범위와 성공 메시지 정확성 문제가 있습니다. 전체 실패 경로 검증이 아직 필요합니다.
8. Undo/Redo는 최대5개 세션 이력입니다. 앱 재시작 후의 장기 데이터 복구 수단이 아닙니다.

원본 `push_history`의 `DataFrame.tolist` 호출은 테스트에서 실제 저장 후 예외를 발생시켰습니다. `services/history.py`에서 열과 행 값을 포함한 지문으로 수정했으며 원본은 바이트 그대로 유지합니다. 월말 호봉 결과28일 같은 계산은 변경하지 않았습니다.

실제 Google Sheets 동시 수정/타임아웃/계정 권한 변경을 운영 환경에서 재현하지 않았습니다. 현재 안전성 검증은 모의 워크시트와 로컬 브라우저에 한정됩니다.
